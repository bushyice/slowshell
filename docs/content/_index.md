&nbsp;

Slowshell is a lightweight wayland shell with the aim to be modestly tweakable and
pluggable. The whole [[Philosophy]] is to keep the program stale unless doing real work.

---

#### What's in the box?

{% <cards> %}
-  Lightweight: Minimal resource usage.
- 󰐱 Pluggable: Pretty capable plugging.
-  Desktop shell: Panels, launchers, wallpapers, menus.
{% </cards> %}
